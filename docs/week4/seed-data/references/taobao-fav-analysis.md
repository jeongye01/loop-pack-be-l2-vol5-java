# Taobao 즐겨찾기 분포 분석

작성일: 2026-10-13

**관측 상품 상위 1%에 즐겨찾기 38.92%, 상위 10%에 83.82%가 집중됐다. 상품의 78.84%는 관측 기간 중 즐겨찾기가 없었다.** 원본 CSV 전체를 읽고 직접 계산한 결과이며, 가정한 파레토 비율이 아니다.

상품·사용자 모집단은 해당 기간에 조회·구매·장바구니·즐겨찾기 중 하나라도 기록된 대상이다. 즐겨찾기가 있는 대상만 골라 계산하지 않았다. 상위 비율의 대상 수는 올림하고, 백분위수는 0건 대상을 포함한 nearest-rank 방식이다.

## 우리 데이터에 적용할 때

- 인기 상품·활동 사용자의 편중을 생성하는 근거로 사용한다. 기존에 가정한 상품 상위 10%의 80%, 사용자 상위 20%의 80%, 상품 0건 비율 50%를 실제 통계와 구분한다.
- 후보 규모인 상품 10만·사용자 1만·좋아요 100만에서는 상품당 평균 10개, 사용자당 평균 100개가 된다. 원본 평균과 다르므로 원본의 절대 건수·백분위수·점유율을 모두 그대로 복제할 수 있다고 가정하지 않는다.
- 상품별 임의 상한 200개는 적용하지 않는다. 사용자·상품 쌍 중복 금지와 사용자 수에 따른 한계는 유지한다. 상품별·사용자별 편중을 함께 만족시킬 수 있는지 생성 방식과 결과로 검증한다.
- 최종 생성 데이터의 상위 점유율·0개 비율·평균·백분위수·최댓값을 원본과 나란히 기록한다. 아직 새 CSV 생성이나 DB 적재는 하지 않았다.

## 해석 범위

이 결과는 **9일간 새로 기록된 즐겨찾기 관계의 분포**다. 취소 기록을 반영한 현재 누적 좋아요 상태가 아니며, 0건도 ‘해당 기간에 기록이 없음’을 뜻한다. 전체 카탈로그·전체 가입자를 분모로 사용한 통계가 아니다. 국내 패션몰의 가격·브랜드별 상품 수·재고 분포를 입증하지 않는다. 편중이 관측됐지만 멱법칙 분포 적합성 검정은 하지 않았다.
