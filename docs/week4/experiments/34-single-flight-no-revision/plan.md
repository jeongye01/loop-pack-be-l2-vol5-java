# Single Flight 유지 + revision 우회 진단

기준점: `b47b390` (로컬 Single Flight 복원), 보존 커밋: `be774e9` (분산 락 및 전체 실험 기록).

- Redis 분산 락 제거, JVM 로컬 Single Flight 유지.
- 실험 플래그로 DB revision SELECT와 변경 시 revision UPDATE를 모두 우회한다.
- 캐시 키는 프로세스별 고정 실험 namespace를 사용한다. TTL은 최신순 첫 페이지 2초, 나머지 300±30초.
- 읽기 1,700 RPS / VU 3,000 + 구매 10건/초 / VU 100, 60초 × 3회. 읽기·구매 각각 p99 ≤100ms.
- 최초 300/700 RPS 예열 후 같은 서버에서는 추가 예열 없이 회복 확인 후 다음 측정.
- 사용자 지시로 이번 변경의 테스트·lint 재실행은 생략하고 배포 빌드 후 부하를 진행한다. seed 응답 일치 검사는 하지 않는다.
- 구매 DB 규칙은 유지한다. revision SQL 비용뿐 아니라 쓰기에 따른 캐시 miss도 없어지는 비교이므로 SQL 한 번의 순수 비용을 분리한 결과로 주장하지 않는다.
- 즉시 무효화가 없어서 표시 재고·수정·삭제의 최신성 계약을 만족한다고 주장하지 않는다. 정합성용 운영 설정이 아닌 병목 진단용이다. 현재 구매 재고가 충분한 격리 데이터로 실행한다.
