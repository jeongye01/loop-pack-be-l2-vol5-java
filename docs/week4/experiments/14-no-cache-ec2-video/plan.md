# キャ시 없는 최신순 — EC2 부하·화면 촬영

- 상태: 완료 — 촬영용 본 측정 1회, SLO 미달
- 기존 캐시 비활성 앱, 최신순·브랜드 없음·첫 페이지 20개·사용자 1.
- 서울 EC2 부하기 → 앱 사설 IP. 공통 실행기와 응답 검증 재사용.
- 준비: 300 → 500 RPS 각 30초, 실행 후 회복 확인. 엄격한 안정화 반복은 하지 않는다.
- 본 측정: 1,700 RPS · VU 3,000 · 60초 · timeout 5초 · **1회만**.
- 사용자가 프론트 화면을 촬영하며 추가 조회할 수 있는 시연 실행이다. 부하기 요청만 정량 집계하고 추가 트래픽은 별도 존재 가능성으로 기록한다.
- 전체 로그 집계는 모든 부하 종료 후 수행한다. 목표 p99 ≤ 200ms·성공률 100%·미시작/미완료 0건과 비교한다.
