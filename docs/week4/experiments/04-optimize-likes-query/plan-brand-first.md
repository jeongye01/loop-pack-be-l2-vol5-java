# 브랜드 상품부터 좋아요 집계

브랜드 필터가 있으면 해당 브랜드의 미삭제 상품을 먼저 고르고, 그 상품의 좋아요만 집계한다. 기존 `uk_product_active_name`의 선두 `brand_id`와 `idx_product_like_product_id`를 활용한다. 브랜드 필터가 없는 경로는 유지한다.

- 변경: 후보 선택 SQL, 좋아요 0개 구간의 offset 계산에 쓰는 양수 상품 수 SQL.
- 확인: 기존 삭제·브랜드·0개·동점·페이지 경계 통합 테스트, HTTP·계측·ArchUnit·Checkstyle.
- 측정: 브랜드 1(5,000상품)·601(333상품)과 무필터, `likes_desc`, `page=0`, `size=20`. 각각 워밍업 3회 후 단건 3회, 기존 응답 전체와 비교.
- 기록: 실행계획의 상품·좋아요 읽은 행 수, 후보 SQL·서버 처리·전체 응답 시간.
