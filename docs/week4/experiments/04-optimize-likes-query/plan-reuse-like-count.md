# 좋아요 정렬 집계값 재사용

좋아요순 후보를 고를 때 계산한 개수를 응답에 재사용해, 선택한 상품의 좋아요 재집계를 제거한다. 저장된 카운터·캐시는 추가하지 않는다. 최신순·가격순은 기존 일괄 집계를 유지한다.

- 비교: N+1 일괄 조회 버전 → 집계값 재사용 버전.
- 요청: 브랜드 필터 없는 `likes_desc`, `page=0`, `size=20`.
- 측정: 같은 EC2·데이터·상세 계측, 워밍업 5회 후 단건 3회 순차 실행. SQL 수·서버 처리·전체 응답 비교.
- 확인: 상품·순서·좋아요 수·`last` 동일, 좋아요 재집계 0회. 삭제·브랜드 필터·좋아요 0개·페이지 경계는 테스트로 확인.

좋아요 전체 집계·정렬 비용은 그대로 남는다. 기대 효과는 중복 집계 1회와 그 호출 비용 제거다.
