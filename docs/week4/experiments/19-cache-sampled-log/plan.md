# 상세 기록 1% 샘플링 부하 실험

- 캐시 ON, 최신순·무브랜드·첫 페이지 20개·사용자 1, 고정 데이터.
- 상세 SQL·단계 계측은 요청 시작 시 1% 무작위 선택. 기존 비동기 출력 유지. 전체 HTTP 지표 유지.
- 서울 EC2 부하기에서 앱 사설 IP로 300→700 RPS 각 30초 예열 후 1,700 RPS·VU 3,000·60초 1회. timeout 5초.
- 전체 요청 응답 내용·성공률·지연 분포·미시작, Tomcat·Hikari·로그 큐·CPU를 확인한다.
- 상세 서버 기록은 표본만 클라이언트 ID와 연결한다. 기존 전수 검증 결과는 그대로 보존하며, 누락 없는 전수 계측으로 판정하지 않는다. 수집한 표본의 중복·미연결·잘림·샘플링 설정을 별도로 확인한다.
- 17번 로그 OFF(평균 23ms, p99 237ms), 18번 비동기 전수(평균 308ms, p99 1,071ms)와 비교한다. 단일 측정·예열 차이로 인과와 개선 배율을 일반화하지 않는다.
- 목표: p99 200ms 이하, 성공률 100%, 미시작·미완료 0건.

- 추가 요청: 같은 배포 버전에서 재예열 후 본 측정 2회 추가. 총 3회 비교하고 기존 결과를 보존한다.
