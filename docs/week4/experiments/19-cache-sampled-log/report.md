# 상세 기록 1% 샘플링 결과

**1,700 RPS에서 평균 4.7ms·p99 51ms. 102,001건 모두 성공했고 미시작·타임아웃·미완료 0건이다. 추가 2회도 p99 73ms·30ms로 세 번 모두 목표 p99 200ms·성공률 100%를 충족했다.**

캐시 ON, 최신순·무브랜드·첫 페이지 20개. 별도 서울 EC2 부하기 → 앱 사설 IP. 300→700 RPS 각 30초 예열 후 VU 3,000·60초·timeout 5초로 측정했다. 700 RPS 예열 p99는 24ms였다.

| 항목 | 로그 출력 OFF — 17번 | 비동기 전수 — 18번 | 비동기 + 1% — 이번 |
| --- | ---: | ---: | ---: |
| 평균 | 23ms | 308ms | **4.7ms** |
| p50 | 6ms | 123ms | **2ms** |
| p95 | 134ms | 882ms | **17ms** |
| p99 | 237ms | 1,071ms | **51ms** |
| 성공률 | 100% | 100% | **100%** |
| 미시작 | 0 | 0 | **0** |

실행마다 예열·JIT 상태가 다른 단일 측정이다. 샘플링이 로그 OFF보다 본질적으로 빠르다거나 위 배율이 재현된다고 결론 내리지 않는다. 17번은 출력만 껐고, 이번에는 미선택 요청의 상세 계측·JSON 생성도 건너뛴다는 차이가 있다.

| 자원·기록 | 결과 |
| --- | ---: |
| 상세 기록 | 990건 / 102,001건 — **0.97%** |
| 표본 서버 내부 평균 / p99 | 3.87ms / 34.75ms |
| Tomcat busy 평균 / 최대 | 7.5 / 30 — 최대 설정 200 |
| 로그 큐 평균 / 최대 | 0 / 0 — 용량 8,192 |
| Hikari pending 평균 / 최대 | 0 / 0 |
| 앱 CPU 평균 — 전체 2코어 | 57.7% |
| DB CPU 평균 — 전체 2코어 | 20.7% |

자원은 5초 간격 13개 표본으로 순간 적체까지 배제하지 않는다. 서버 내부 지연은 990건 표본 통계이며 전체 응답 지연은 102,001건 전체 통계다. 캐시 hit 증가 102,003건(사전·회복 점검 포함), miss·fill 증가 0건이다. Tempo는 아직 연결하지 않았다.

검증: 전체 클라이언트 응답 내용이 기준 응답과 일치했다. 받은 상세 기록은 중복·미연결·잘림 없이 연결됐으며 모두 sampleRate=0.01이다. 선택된 기록이 전부 전달됐음을 증명하는 별도 선택 카운터는 없으므로 로그 무손실을 주장하지 않는다. 기존 실행기의 전수 서버 연결 검증은 변경하지 않았다. 따라서 `result.json`의 `status=failed`, `measurementComplete=false`는 의도적으로 전수 기록을 하지 않은 데 따른 것이며 HTTP 실패가 아니다. 표본 검증은 별도 파일에 보존했다.

## 추가 2회 재현 확인

동일 이미지·데이터·캐시·1% 샘플링을 유지했다. 앱 재시작 없이 300→700 RPS 각 30초 재예열 후 1,700 RPS·VU 3,000·60초를 2회 추가했고, 실행 사이 회복을 확인했다. 추가 예열 p99는 각각 4ms·6ms였다.

| 실행 | 평균 | p95 | p99 | 성공 건수 | 성공률 | 미시작 | 상세 표본 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| [1회차](results/20261014T192423-measure-1700-f54956/result.json) | 4.71ms | 17ms | **51ms** | 102,001 | 100% | 0 | 990 |
| [2회차](results/20261014T193100-measure-1700-9cdbf1/result.json) | 4.98ms | 14ms | **73ms** | 102,001 | 100% | 0 | 988 |
| [3회차](results/20261014T193229-measure-1700-d4d154/result.json) | 3.45ms | 11ms | **30ms** | 102,000 | 100% | 0 | 1,017 |

세 번 모두 타임아웃·미완료·응답 불일치 0건이며, 캐시 miss·fill·읽기/쓰기 오류 증가 0건이다. 받은 상세 표본은 중복·미연결·잘림 없이 연결됐다. 각 Run의 `sampling-validation.json`과 `resource-summary.json`에 별도 기록했다. 기존 전수 검증의 failed 표시는 위 설명대로 유지한다.

이 결과는 **동일 최신순 첫 페이지에 대한 캐시 hit 중심·고정 데이터·EC2 사설 경로**에서 재현한 것이다. 캐시 miss·다른 필터·데이터 변경·사용자 인터넷 경로까지 동일 성능을 보장하지 않는다. 회차별 p99를 평균 내어 전체 p99로 표기하지 않는다.
