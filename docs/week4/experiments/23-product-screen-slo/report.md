# 세 API 조합 현황 탐색

2026-10-15, 배포 `catalog-b2e84c4`, 부하 EC2 → 앱 사설망. 목록 → 좋아요 수·재고 병렬 조회. 목표는 1,700 방문/초에서 전체 p99 ≤ 200ms였다.
