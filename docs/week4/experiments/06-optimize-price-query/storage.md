# 가격순 인덱스 추가 전후 용량

DDL 전·완료 직후 같은 EC2에서 `df -B1 /`, `INNODB_TABLESPACES`, `mysql.innodb_index_stats`를 수집했다. 데이터 변경 없음.

| 항목 | 추가 전 | 추가 후 | 차이 |
| --- | ---: | ---: | ---: |
| EC2 루트 디스크 사용량 | 6,274,752,512 B | 6,337,687,552 B | **약 60.02MiB 증가** |
| `df` 사용률 | 33% | 33% | 정수 표시는 동일 |
| 상품 테이블 파일 크기 | 281,018,368 B (268MiB) | 343,932,928 B (328MiB) | **60MiB 증가** |
| 무필터 가격순 인덱스 | 없음 | 26,804,224 B (25.56MiB) | 신규 |
| 브랜드 가격순 인덱스 | 없음 | 36,257,792 B (34.58MiB) | 신규 |

신규 인덱스 페이지 통계 합계는 **60.14MiB**다. 파일 크기 증가량과 인덱스 페이지 통계는 서로 다른 기준이다. 파일 안의 기존 여유 공간·할당과 통계 특성 때문에 반드시 일치하지 않는다. EC2 전체 디스크에는 로그 등도 포함되므로 증가분 전부를 인덱스 파일에만 귀속하지 않는다.
