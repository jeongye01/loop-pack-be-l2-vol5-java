# 실험 로그 AsyncAppender — 구현·비교 결과

**실험 로그 비동기화와 전수 보존을 확인했다. 응답 p99는 1,071ms로 목표 미달이며, 이번 1회 결과만으로 성능 개선을 확정하지 않는다.** 큐 적체는 작았지만 DB 커넥션 대기와 큰 JIT 증가가 관측됐다.

## 변경

`EXPERIMENT_TRACE`만 `experiment-async` 프로필에서 AsyncAppender로 출력한다. 기존 `EXPERIMENT_JSON` 내용·JSON 생성·SQL/단계 계측·Docker 로그 수집은 유지한다. additivity=false로 동기 root에 중복 출력하지 않는다.

큐 8,192건, discardingThreshold=0, neverBlock=false: INFO 폐기 없이 포화 시 요청 스레드에 backpressure를 건다. 정상 종료 flush 최대 30초, Docker 종료 유예 75초. 강제 종료·출력 장애까지 로그 영구 보존을 보장하는 설정은 아니다.
