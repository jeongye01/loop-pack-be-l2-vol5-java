# commerce-api 설계

## 버드뷰

```
고객   ── /api/v1/**       ──┐
                             ├──▶ API 서버 (commerce-api) ──▶ DB
관리자 ── /api-admin/v1/** ──┘
```


| 요청자 | 경로                 | 요청하는 기능                                                                            |
| --- | ------------------ | ---------------------------------------------------------------------------------- |
| 고객  | `/api/v1/**`       | 브랜드 상세, 상품 목록·상세, 좋아요 등록·취소, 내 좋아요 목록, 내 포인트 충전, 내 잔액 조회, 주문 생성, 주문 확정, 내 주문 목록·상세 |
| 관리자 | `/api-admin/v1/**` | 브랜드 전체 CRUD, 상품 전체 CRUD, 상품 재고 변경, 주문 목록·상세                                        |
