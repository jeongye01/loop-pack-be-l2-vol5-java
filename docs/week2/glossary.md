# commerce-api 용어집

[요구사항 문서](./requirements.md)에서 도출한 유비쿼터스 랭귀지다.


| 용어          | 정의                                                                                            | 코드 이름                                 |
| ----------- | --------------------------------------------------------------------------------------------- | ------------------------------------- |
| 고객          | 브랜드·상품을 조회하고 좋아요·포인트·주문을 이용하는 주체. 자신의 것만 다루며, 관리자 기능은 쓸 수 없다. 주문 맥락에서는 **구매자**로도 부르며 같은 대상이다  | `User`                                |
| 브랜드         | 상품이 속하는 대상. 존재하며 삭제되지 않은 것만 상품이 참조할 수 있다                                                      | `Brand`                               |
| 상품          | 이름·가격·소속 브랜드·재고를 갖고 주문에 사용되는 대상                                                               | `Product`                             |
| 재고          | 상품의 가용 수량. PG 결제에서는 예약 시 줄고 예약 확정 시 추가 차감되지 않는다. 포인트 결제에서는 주문 확정 시 차감된다. 주문 생성만으로는 변하지 않는다    | `Stock`                               |
| 포인트         | 고객의 잔액. 1포인트는 1원이며 충전으로 늘고 포인트 결제 시 차감된다. 신규 PG 주문에서는 사용하지 않는다                                | `Point`                               |
| 좋아요         | 고객이 상품에 등록하는 표시                                                                               | `Like`                                |
| 주문          | 여러 품목과 합계를 갖는 고객의 구매 요청. 결제 요청에 사용하는 **주문 금액**이 이 합계다                                         | `Order`                               |
| 주문 품목       | 주문에 포함된 상품·수량·단가. 상품을 삭제해도 함께 삭제되지 않는다                                                        | `OrderItem`                           |
| 결제 결과       | 확정에 성공한 주문이 남기는 결제액과 결과                                                                       | `PaymentResult`                       |
| 주문 상태       | 주문 생성 시 `DRAFT`, PG 결제 대기 시 `PAYMENT_PENDING`, 성공 반영 후 `CONFIRMED`. 실패·미확인 세부 상태는 후속 계약에서 다룬다 | `OrderStatus`                         |
| `DRAFT`     | 결제 전 주문 상태. 재고 예약과 결제를 아직 시작하지 않았고 결제 결과가 없다                                                  | `OrderStatus.DRAFT`                   |
| `CONFIRMED` | 결제 완료 주문 상태. 결제 결과를 갖는다. PG 결제에서는 재고 예약이 확정되며, 과거 포인트 결제에서는 재고와 포인트가 차감된 상태다                  | `OrderStatus.CONFIRMED`               |
| PG          | 주문의 결제를 처리하고 거래 상태를 제공하는 외부 시스템. 실습에서는 로컬 테스트 PG를 사용한다                                        | 구현 이름 미정                              |
| 재고 예약       | PG 요청 전에 특정 주문의 수량을 확보한 사실. 가용 재고에서 제외되지만 판매 확정은 아니다                                          | 구현 이름 미정                              |
| 재고 예약 확정    | 결제 성공 후 예약한 수량을 해당 주문에 사용한 것으로 확정하는 것. 가용 재고의 추가 차감은 없다                                       | 구현 이름 미정                              |
| 결제 대기       | 재고를 확보하고 PG 결제 결과를 기다리는 주문 상태                                                                 | `OrderStatus.PAYMENT_PENDING` (설계 목표) |
