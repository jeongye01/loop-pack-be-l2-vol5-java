# commerce-api 요구사항

2주차 과제 문서에서 고객과 관리자에게 제공해야 하는 기능, 결과, 업무 규칙을 추린 것이다. 클래스·패키지·저장 방식·HTTP·테스트 같은 구현 방법에 관한 지시는 제외한다. [설계 문서](./commerce-api-design.md)의 근거는 이 문서의 ID를 가리킨다.

요구사항 ID는 `R-그룹-순번` 형식이다. 한 번 붙인 ID는 바꾸지 않으며, 새 요구사항은 그룹의 다음 순번을 받는다.

## 요구사항

### 사용자와 접근 범위 (`ACCESS`)

| R-ACCESS-02 | 관리자는 브랜드·상품·재고를 관리하고 구매자들의 주문을 조회할 수 있다. | 과제 문서 · `3. 기본 기능 구현 > 관리자` |
| R-ACCESS-03 | 고객은 자신의 좋아요·포인트·주문만 다룰 수 있다. | 과제 문서 · `4. 실행·제출` 첫 문단 |
| R-ACCESS-04 | 관리자 기능은 관리자만 사용할 수 있고 일반 사용자와 식별되지 않은 사용자는 사용할 수 없다. | 과제 문서 · `4. 실행·제출 > 관리자 HTTP 테스트 실행` |
| R-ACCESS-05 | 식별 정보가 없거나 존재하지 않는 사용자의 고객 요청은 거절한다. | 과제 문서 · `4. 실행·제출` 첫 문단 |
