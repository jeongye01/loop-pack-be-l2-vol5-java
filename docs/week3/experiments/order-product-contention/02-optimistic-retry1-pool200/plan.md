# 낙관적 락·재시도 1회 실험 계획

## 전략

- JPA `@Version`으로 주문·상품·사용자 갱신 충돌을 감지한다.
- 충돌 시 새 트랜잭션에서 최대 1회 재시도한다.
- 재시도 간 대기 시간은 0ms다.
- 관리자 상품 수정은 주문 부하 중간에 1회 실행한다.

## 검증

- `OrderConcurrencyTest`를 실행해 성공·업무 거절·기술 오류와 최종 DB 상태를 기록한다.
- S1 부하를 10·30·100 RPS, 각 60초·3회 측정한다.
- 주문 trace와 관리자 trace를 분리하고 관리자 trace에는 낙관적 락에서 행 잠금 대기가 적용되지 않음을 기록한다.
