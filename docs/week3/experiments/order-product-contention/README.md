# 주문 확정·상품 수정 동시성 실험

같은 상품을 대상으로 고객 주문 확정과 관리자 상품 수정을 동시에 실행해 락 전략별 정합성과 응답 특성을 비교한다.

| 실험 | 전략 | 상태 |
| --- | --- | --- |
| `01-pessimistic-pool200` | `PESSIMISTIC_WRITE`, 재시도 없음 | 완료 결과 보존 |
| `02-optimistic-retry1-pool200` | JPA `@Version`, 재시도 1회 | 실행 예정 |

공통 시나리오와 부하 조건은 각 실험 폴더의 계획서에서 재사용한다. 실험별 결과와 trace는 해당 폴더 아래에만 저장한다.
