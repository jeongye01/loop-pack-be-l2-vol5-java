# 낙관적 락 재시도 2회 실험 계획

## 질문과 가설

같은 자원 조건에서 낙관적 충돌을 최대 2회 재시도하면 재시도 없이 실행할 때보다 업무 성공이 늘어나는지, 재시도 비용으로 지연 시간이 커지는지 확인한다.

## 고정 조건

| 항목 | 값 |
| --- | --- |
| 전략 | JPA `@Version` 낙관적 락 |
| 재시도 | 최대 2회, 대기 0ms |
| 애플리케이션 풀 | Hikari 최대 40, 최소 유휴 30, 대기 3초 |
| MySQL | `max_connections=50`, 기본 격리 수준 |
| 부하 | S1, 10·30·100 RPS, 각 60초·3회 |

## 검증

동시성 테스트 4종을 10회 실행하고 실패 assertion을 결과로 기록한다. S1 HTTP 부하에서 성공·업무 거절·낙관적 충돌·기술 오류를 분리하고 p50/p95/p99, 전체·성공 처리량, 최종 주문·재고·잔액 정합성을 확인한다.
