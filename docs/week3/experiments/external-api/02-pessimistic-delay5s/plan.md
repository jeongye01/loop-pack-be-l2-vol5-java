# 비관적 락·외부 API 5초 지연 실험 계획

## 질문과 가설

외부 결제 API가 5초 지연되어도 DB 트랜잭션 밖에서 호출하면 비관적 잠금의 행 점유와 커넥션 풀이 보호되는지 확인한다.

## 고정 조건

| 항목 | 값 |
| --- | --- |
| 전략 | JPA `PESSIMISTIC_WRITE` |
| 외부 API | 가짜 결제 승인, 요청당 5초 |
| 호출 위치 | DB 트랜잭션 밖 |
| 애플리케이션 풀 | Hikari 최대 40, 최소 유휴 30, 대기 3초 |
| MySQL | `max_connections=50`, 기본 격리 수준 |
| 부하 생성기 | 600 VU |
| 부하 | S1, 10·30·100 RPS, 각 60초·3회 |

## 검증

현재 외부 API 실험 보고서 형식을 유지해 전체 p95, 전체·성공 TPS, 요청 미시작 수, 결제 승인·취소 보상, 최종 주문·재고·잔액 정합성을 기록한다. p99는 Run JSON에만 보존한다.
