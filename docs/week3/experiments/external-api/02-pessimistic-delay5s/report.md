# 비관적 락·외부 API 5초 지연 실험 결과

가짜 결제 API를 주문 확정 API 밖에서 먼저 호출하고, 요청당 5초 지연을 주었다. DB 확정 실패 시 가짜 결제 취소 API를 호출했다.

## 핵심 결과

| 목표 RPS | Run 수 | 성공 범위 | 품절 거절 범위 | 기술 오류 범위 | 전체 p95 범위(ms) | DB 정합성 |
| ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 10 | 3 | 180~180 | 420~420 | 0~0 | 5038~5050 | 통과 |
| 30 | 3 | 540~540 | 1260~1260 | 0~0 | 5026~5027 | 통과 |
| 100 | 3 | 1800~1800 | 4200~4200 | 0~0 | 5012~5031 | 통과 |

- 측정 Run은 모두 성공·품절 거절로 끝났고 기술 오류·데드락·미시작 요청은 0건이었다.
- 가짜 결제 승인 지연 5초가 포함되어 전체 p95가 약 5초로 나타났다.
- 품절 거절 17,640건은 모두 가짜 결제 취소 보상을 기록했고, 최종 주문·재고·잔액 정합성은 모든 Run에서 통과했다.

## 해석

외부 호출을 부하 생성기에서 먼저 수행했기 때문에 5초 지연은 전체 HTTP 응답시간에는 포함됐지만 DB 잠금 보유시간에는 포함되지 않았다. 비관적 락은 모든 부하 단계에서 업무 결과와 정합성을 유지했고, 외부 승인 후 DB 확정이 실패한 품절 요청은 취소 보상으로 정리됐다.
